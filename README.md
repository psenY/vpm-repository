## ⚡ 一键安装到 VCC / ALCOM

点击上方绿色徽章，或直接访问 [网页端一键安装页面](https://psenY.github.io/vpm-repository/) 即可快速添加。

或者在 VCC / ALCOM 的设置中手动添加此链接：
```text
https://psenY.github.io/vpm-repository/index.json
```
