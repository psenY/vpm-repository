## 📖 仓库简介 (Introduction)

本仓库是 **psenY7** 专为 VRChat 创作者开发的实用工具与优化插件合集订阅源。  
通过将本仓库添加到 **VCC (VRChat Creator Companion)** 或 **ALCOM**，你可以在任何 Unity 模型工程中随时一键安装、升级与管理以下所有插件。

👉 **[在线 Web 订阅源主页 (一键添加与手动下载)](https://pseny.github.io/vpm-repository/)**

---

## ⚡ 一键添加到 VCC / ALCOM (Quick Install)

### 方式 1：网页端一键添加 (推荐 ⭐)
1. 点击打开：**[psenY7's VPM Listing 网页主页](https://pseny.github.io/vpm-repository/)**。
2. 点击页面顶部的绿色 **`Add to VCC`** 按钮，浏览器将自动唤起 VCC / ALCOM 客户端并确认添加。

### 方式 2：客户端手动添加
在 **VCC** 或 **ALCOM** 客户端中：
1. 进入 **Settings (设置)** -> **Packages (包管理)** 标签页。
2. 点击 **Add Repository (添加仓库)**。
3. 粘贴以下订阅源 URL 并确认：
   ```text
   https://pseny.github.io/vpm-repository/index.json
   ```
4. 进入你的任意 Avatar 工程，即可在插件列表中搜索并一键勾选安装！
